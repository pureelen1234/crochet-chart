뜨개 지시문을 한 줄씩 입력하면 코바늘 기호 도안이 자동으로 그려지고, 기호를 손으로 옮기거나 돌려서 다듬은 뒤 PDF/PNG로 저장하는 웹앱입니다. 아이폰 Safari에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

서버 없이 동작하는 정적 사이트라 GitHub Pages에 그대로 올리면 됩니다. 입력한 도안은 각 기기(브라우저)에 자동 저장되고, 백업 파일(.json)로 내보내기/불러오기가 가능합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 디자인 (라이트/다크 자동) |
| `symbols.js` | **기호 사전** — 기호를 추가·수정하는 곳 |
| `parser.js` | 도안 텍스트 → 코 목록 (문법 처리, 코 수 계산) |
| `layout.js` | 코 목록 → 좌표 (원형 / 평면 배치). 새 규격은 여기에 추가 |
| `app.js` | 앱 본체 (저장, 그리기, 편집, PDF/PNG) |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | 홈 화면 앱(PWA) 설정 |
| `serve.ps1`, `serve.mjs` | 컴퓨터에서 미리보기용 로컬 서버 (윈도우 `powershell -File serve.ps1`, 맥 `node serve.mjs` → http://localhost:8765) |

## 기호 추가하기

`symbols.js`의 `STITCHES` 배열에 한 줄 추가하면 입력 문법·범례·도안에 모두 반영됩니다.

```js
{
  id: "puff", name: "퍼프뜨기", aliases: ["퍼프뜨기", "퍼프", "puff"],
  consumes: 1, produces: 1, h: 9,
  draw: () => `<path d="M0 9 L0 -9 M-5 -6 Q0 -12 5 -6"/>`
}
```

- `consumes`: 전 단에서 사용하는 코 수 (사슬처럼 전 단과 무관하면 0)
- `produces`: 이 기호가 만드는 코 수
- `h`: 기호 세로 반높이 (늘림·줄임 부채꼴의 회전 중심)
- `draw()`: 원점(0,0)이 기호 중심인 SVG 조각. 선 색·굵기는 자동으로 적용됩니다.

## 키패드로 입력하기 (아이패드·아이폰)

키보드 없이 기호 버튼을 눌러 적습니다. 단 칩을 누르면 그 단에 이어 적고, `↵ 다음 단`으로 새 단을 시작합니다. 쉼표·띄어쓰기는 자동. 예: `사슬` `2` `공간에` `(` `한길긴뜨기` `3` `사슬` `2` `한길긴뜨기` `3` `)` `×` `4` → `사슬 2 공간에 (한길긴뜨기 3, 사슬 2, 한길긴뜨기 3)*4`. 키패드가 만드는 건 아래 문법의 텍스트이므로, 키보드가 있으면 직접 고쳐도 됩니다("⌨ 키보드로 입력").

## 도안 입력 문법

```
매직링                                   ← 첫 줄: 시작 (매직링 / 사슬 원형 시작 N / 기초 사슬 N)
기둥사슬 1, 짧은뜨기 6, 빼뜨기             ← 1단. 기둥사슬 = 단 시작 사슬(세로로 쌓임), 빼뜨기 = 이음
기둥사슬 1, 짧은뜨기 2코 늘려뜨기 6, 빼뜨기  ← 2단: 한 코에 2개(늘림) ×6
기둥사슬 1, (짧은뜨기, 늘려뜨기)*6, 빼뜨기   ← 3단: 괄호 반복
짧은뜨기 2코 모아뜨기 9                    ← 줄임
짧은뜨기 앞이랑뜨기 6, 한길긴뜨기 뒷이랑뜨기   ← 앞·뒤 반코 (이랑뜨기만 쓰면 짧은뜨기 뒷이랑)
긴뜨기 앞걸어뜨기, 한길긴뜨기 뒤걸어뜨기      ← 기둥에 걸어 뜨기 (앞걸어뜨기만 쓰면 한길긴뜨기)
긴뜨기 3코 구슬뜨기, 한길긴뜨기 5코 팝콘뜨기  ← 가닥 N개 (코 수 생략 시 구슬 3, 팝콘 5)
한길긴뜨기 3, 사슬 2                       ← 사슬은 이어진 묶음으로 그려짐 (사각에서는 모서리)
사슬2 공간에 (한길긴뜨기 3, 사슬 2, 한길긴뜨기 3)   ← 전 단 사슬 공간에 괄호 전체를 뜸 (부채꼴)
```

- 한 줄이 한 단, 반시계방향, 12시에서 출발. `3단:` 같은 머리말은 무시.
- `기둥사슬 1` = 0코, `기둥사슬 2` 이상 = 1코(전 단 첫 코 대신).
- 단 끝 `빼뜨기`는 이음(●)으로 표시하고 코 수에 넣지 않음.
- 사각 모티브: 사슬 2 이상 묶음이 모서리로 배치됨 (1단은 4개가 있어야 정사각형이 됨).
- 전 단과 코 수(또는 사슬 공간 수)가 맞지 않으면 노란색 경고.

## 규격 추가하기

`layout.js`의 `LAYOUTS`에 `{ name, fn }`을 추가하면 규격 선택 버튼에 자동으로 나타납니다. 원형/사각은 `layoutRing(p, shape)` 하나를 공유하므로, 투영 함수(`projCircle`, `projSquare`)만 새로 만들면 다른 모양(타원·육각 등)도 쉽게 붙일 수 있습니다.
